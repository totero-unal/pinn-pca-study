# Datos

`raw/burgers_shock.mat` es una copia sin cambios del archivo de datos Burgers usado en el proyecto PINNs anterior. Contiene las variables `x`, `t` y `usol`; las predicciones de la PINN no se guardan en esta carpeta.

El ajuste de PCA usa únicamente snapshots de los tiempos asignados al conjunto de entrenamiento. Los snapshots de validación y prueba no participan en el cálculo de la base PCA.
